# Time Dilation in Aerospace Systems

Extended Project Qualification (EPQ) investigating the significance of
relativistic time dilation in modern aerospace systems.

**Grade:** A - 44/50  
**Duration:** September 2025 – February 2026

## Overview

This project investigates relativistic time-dilation effects across:
- GPS satellite systems
- Hohmann orbital transfers
- Escape-velocity trajectories

## Key Findings

- Calculated a net GPS clock drift of approximately +38 μs/day
- Estimated an uncorrected positional error of approximately 10 km/day
- Found time-dilation effects to be negligible for typical orbital manoeuvres
  and escape-velocity trajectories
